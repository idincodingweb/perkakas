## 💡 ARCHITECTURE REVERSE — BAGAIMANA KOMUNIKASI DART ↔ JAVA

```
DART SIDE (libapp.so)                    JAVA SIDE (smali)
══════════════════════                   ════════════════

MethodChannel("snake_channel")  ─────►  Entry implements kd0$c
  .setMethodCallHandler()                       │
       │                                        │ method C(id0, kd0$d)
       │  ┌── "0" ──────────────────►  Native.djp(I)[B]
       │  ├── "A" ──────────────────►  Toast.makeText()
       │  ├── "B" ──────────────────►  SharedPreferences.edit().putString() ✍️
       │  ├── "C" ──────────────────►  setCallback + init storage permission
       │  ├── "D" ──────────────────►  SharedPreferences.getString() 📖
       │  ├── "E" ──────────────────►  Open URL di browser
       │  ├── "F" ──────────────────►  Return static string i
       │  └── "G" ──────────────────►  Request permission (notification)
       │
       └──── hasil kembali ke Dart via kd0$d.c(Object)
```

### Alur MethodChannel di Flutter:
1. **`kd0`** = class MethodChannel (belum ditemukan file `kd0.smali` parent)
2. **`kd0$a`** = handler yang nerima raw ByteBuffer dari Flutter engine, decode ke `id0`, trus panggil `kd0$c.C()`
3. **`kd0$b`** = callback yang handle result dari Dart ke Java
4. **`kd0$c`** = **interface** dengan method `C(id0, kd0$d)` — **DIIMPLEMENT OLEH `Entry`**
5. **`kd0$d`** = **interface** callback: `c(Object)`=sukses, `b(err,msg,data)`=error, `a()`=notImplemented
6. **`vi`** = DartMessenger — implementasi BinaryMessenger, method `j()` = `setMessageHandler`
7. **`id0`** = class data container — field `a` (String = channel code), field `b` (Object = payload)

## 💥 STRATEGI BYPASS PREMIUM

### Opsi 1: Patch Channel `"D"` (READ PREFS) — REKOMENDASI 🏆

**File target:** `Entry.smali`
**Method:** `C(Landroidx/appcompat/view/menu/id0;Ldroidx/appcompat/view/menu/kd0$d;)V`
**Label target:** `:cond_4` (channel "D")

**Patch:** Ganti isi handler channel `"D"` dari baca SharedPreferences jadi **return `Boolean.TRUE` langsung**.

```smali
:cond_4
    sget-object p1, Ljava/lang/Boolean;->TRUE:Ljava/lang/Boolean;
    invoke-interface {p2, p1}, Landroidx/appcompat/view/menu/kd0$d;->c(Ljava/lang/Object;)V
    return-void
```

**Efek:** Semua request READ dari Dart lewat channel "D" return `true` — Dart pikir semua fitur premium sudah aktif.

**Resiko:** Karena channel "D" baca semua key (bukan cuma premium), data non-premium yang dibaca lewat channel ini juga kena. Mungkin ada bug kecil.

### Opsi 2: Patch Channel `"B"` + Inject Manual via ADB

Karena channel `"B"` nulis ke SharedPreferences, kita bisa inject key-value lewat ADB:
```bash
adb shell
run-as com.snake
echo '{"isPro":"true","premium":"true"}' > /data/data/com.snake/shared_prefs/com.snake.xml
```
Tapi butuh root/ADB.

### Opsi 3: Patch Premium Lewat Hex di libapp.so

Dari hasil extract string `libapp.so`, ditemukan:
- **Offset `0x000494bf`** → string `"Unlock it"` 🔥 (label tombol premium)
- **Offset `0x0004a4c5`** → string `"productId"` (in-app purchase)
- **Offset `0x000477f8`** → string `"Subscribe"` (subscription)

Tapi patch di libapp.so butuh reverse lebih lanjut (IDAF/Ghidra) — tidak optimal di HP.

### Opsi 4: Patch Entry.onCreate — Brutal Method Return

```smali

.end method
```

**⚠️ Resiko tinggi:** Aplikasi force close karena Flutter engine tidak diinisialisasi. Udah terbukti dari awal — app force close.
