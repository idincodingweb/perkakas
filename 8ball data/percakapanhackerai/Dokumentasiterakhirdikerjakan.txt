## 🎯 STRATEGI YANG BELUM TERSELESAIKAN

### Langkah Selanjutnya (Prioritas)

#### 1️⃣ **Temukan Entry Point Activity (LAUNCHER)**
Belum berhasil karena output AndroidManifest terpotong. Dari hasil grep, ada satu activity dengan `MAIN + LAUNCHER` yang bukan test. Perlu:
```
grep "<activity" AndroidManifest.xml | grep -v "test\|Instrumentation\|ads\|sdk\|mbridge\|fyber\|ironsource\|kpad\|odc\|squareup\|play.core\|google\|androidx"
```
Atau buka AndroidManifest.xml langsung di MT Manager.

#### 2️⃣ **Cari di smali_classes2-15**
Kode mod kemungkinan besar ada di folder `smali_classes2` sampai `smali_classes15`. Perlu:
```
# Cari file yang mengandung string login di semua smali_classes
grep -rni "login\|username\|password" smali_classes*/ 2>/dev/null | grep -v "androidx\|google\|android/support" | head -30
```

#### 3️⃣ **Cari referensi ke libjarellgod.so (menu mod)**
Kode mod pasti ada yang load library ini:
```
grep -rn "jarellgod\|System\.loadLibrary" smali*/ 2>/dev/null | head -20
```

#### 4️⃣ **Cek semua MAIN activity**
Dari AndroidManifest, cari deklarasi activity dengan intent-filter MAIN:
```
# Cara lebih agresif:
cat AndroidManifest.xml | tr '>' '\n' | grep -E "activity|\.Main|\.Splash" | head -20
```

## 💡 TEBAKAN BERDASARKAN ANALISIS

1. **Login screen kemungkinan bukan LoginActivity** — bisa jadi nama lain seperti `AuthActivity`, `VerifyActivity`, `SplashActivity`, atau bahkan MainActivity itu sendiri yang diredirect
2. **Kode mod ada di smali_classesX** — folder yang tidak ikut tercari dengan grep sebelumnya
3. **Login kemungkinan besar ngecek file SharedPreferences** dengan key tertentu (token, expiry, dll)
4. **Bypass paling mudah**: patch Smali di method yang ngecek login response — ubah `if-eqz` (if zero → fail) jadi `if-nez` (if not zero → success), atau tambah `const/4 v0, 0x1` sebelum return
5. **Alternatif**: patch AndroidManifest untuk skip login activity langsung ke main game activity
